# Безопасный выпуск

Новая версия не опубликована. Ветка: feature/vozmiprompt-v2. Production и origin не изменены.

1. Владелец просматривает локальную версию и явно разрешает публикацию.
2. Проверить Settings → Pages: фактический домен, ветку и каталог публикации. Из текущей среды запрос к kyrokzai.github.io блокировался прокси; считать URL подтверждённым нельзя.
3. После проверки URL выполнить `python3 scripts/site-metadata.py --site-url https://ПОДТВЕРЖДЁННЫЙ-АДРЕС/путь/`. Скрипт создаёт canonical, абсолютные OG/Twitter image URL, sitemap.xml и ссылку на него в robots.txt. Он не публикует сайт. Сейчас эти зависящие от домена поля намеренно не активированы.
4. Выполнить `node tests/smoke.cjs` при запущенном сервере; проверить HTML Lighthouse-отчёт. Для проверки подкаталога запустить сервер на /workspace и передать BASE_URL=http://127.0.0.1:8001/vozmiprompt-demo/.
5. Сохранить SHA текущего production и доступ к резервной копии `/workspace/vozmiprompt-baseline.bundle`. Оригиналы всех встроенных файлов сохранены в assets; SHA-256 записаны в docs/media-manifest.json. Старая версия страницы доступна в исходном коммите cf310282a6e2ae622b6cc76b0d7edf25c8dfb1fa; альтернативный vozmiprompt-demo.html сохранён.
6. Только с разрешения владельца отправить feature-ветку и создать PR. Не включать автоматический Pages workflow, не делать force push. Проверить выбранный способ публикации перед merge.
7. После согласованного выпуска проверить главный URL, ресурсы под подкаталогом, видео, форму, метаданные и mobile Lighthouse. Откат — revert коммита выпуска через PR и прежний способ Pages deployment, без переписывания истории.
