# Приёмка VOZMI PROMPT 2.0

## Реализация
- Новый адаптивный интерфейс: hero, портфолио с шестью фильтрами, услуги, два существующих коммерческих кейса, процесс, студия, FAQ и контакты.
- Реальные материалы из исходного сайта; никакого нового стока, выдуманных клиентов, отзывов или показателей.
- Шоурил по действию пользователя, постер, пауза при уходе из viewport/вкладки. Отсутствие фоновой загрузки видео при старте и при reduced motion.
- Доступный dialog, Escape, возврат фокуса, остановка и выгрузка видео при закрытии. Крупные touch-цели.
- Структурированная WhatsApp-заявка с валидацией, кодированием, предупреждением и без ложного статуса отправки.
- Оригиналы медиа сохранены по SHA-256; WebP 480/960 и faststart MP4 без перекодирования. Старый HTML-вариант сохранён.
- SEO/structured data, favicon, robots; генератор доменных метаданных, событийные точки аналитики без внешнего трекера.

## Lighthouse
Тот же локальный Python HTTP-сервер, Chromium и Lighthouse 13.6.0; стандартный mobile preset. Финальные прогоны выполнены последовательно без параллельного QA. Исходный baseline — один сохранённый прогон; финал — медиана трёх. Это лабораторные измерения, не полевые CWV.

|---|---:|---:|
| Performance | 41 | 98 (99 / 97 / 98) |
| Accessibility | 100 | 100 |

Первый прогон во время параллельных тестов дал 87 и TBT 490 мс. Его не скрываем: файл lighthouse.report.json сохранён отдельно. После устранения ошибок отображения и остановки параллельной нагрузки получены три финальных измерения. INP, 60 FPS и реальные устройства не измерялись.

## QA
`tests/smoke.cjs` проверяет девять ширин 320/375/390/430/768/1024/1280/1440/1920, mobile menu, все категории, отсутствие переполнения, dialog/Escape/фокус, формирование и валидацию WhatsApp URL, отсутствие автозапуска с reduced motion, pause, FAQ, декодирование изображений, каждый ролик портфолио, landscape, компонент сравнения на явно тестовых несвязанных изображениях. Перехват window.open предотвращает отправку/открытие реальных заявок.
Артефакты: /workspace/vozmi-v2-results (JSON, отчёты Lighthouse, полные скриншоты и hero). Исходные артефакты: /workspace/vozmi-audit.

Финальный прогон после всех изменений: PASS на всех 9 ширинах с BASE_URL=http://127.0.0.1:8001/vozmiprompt-demo/. Нулевые pageerror и HTTP-ошибки. Все пять видео портфолио начали воспроизведение; изображения декодированы. Клавиатурное управление компонентом сравнения проверено только на тестовой паре, публичного кейса нет. Сводки сохранены в docs/playwright-results.json и docs/lighthouse-metrics.json. Финальные desktop/mobile hero-скриншоты просмотрены; стрелки отображаются SVG, переполнения заголовков нет.
