# Отдельный preview с iPhone

Архив VOZMI-PROMPT-2-preview.zip содержит только статический сайт: index.html в корне, assets, robots.txt и .nojekyll. В HTML установлен noindex, nofollow, noarchive. Это ограничение индексации, не пароль. Включены существующий текстовый бренд и все медиа; оригинальный логотип пока не получен.

## Cloudflare Pages — загрузка ZIP

1. Скачайте ZIP на iPhone в приложение «Файлы». Не используйте Download ZIP всего репозитория.
2. Откройте https://dash.cloudflare.com/ в Safari и войдите в аккаунт (при необходимости создайте бесплатный). Компьютер не нужен.
3. Откройте Workers & Pages → Create application → Pages → Use direct upload / Upload assets. В некоторых версиях панели переход называется Get started → Drag and drop your files. Выберите именно Pages со статическими файлами.
4. Создайте НОВЫЙ проект, например vozmiprompt-v2-preview. Не выбирайте существующий сайт, основной домен или интеграцию production-репозитория.
5. Нажмите область выбора файлов → Choose Files / «Выбрать файлы» → выберите скачанный ZIP. Cloudflare Pages Direct Upload принимает ZIP; распаковка на iPhone не нужна.
6. Нажмите Deploy site / Deploy. После завершения откройте HTTPS-ссылку, выданную Cloudflare (домен pages.dev). Имя может быть изменено при конфликте — используйте фактически выданный адрес.
7. Если элементы панели скрыты в мобильном виде, выберите в меню Safari «Запросить настольный веб-сайт».
8. Откройте выданную ссылку в новой вкладке: проверьте меню, фильтры, каждый ролик и форму. WhatsApp открывает текст заявки, но не отправляет её автоматически.

Это отдельный облачный сайт: после успешного развёртывания он работает при выключенном ПК. DNS и основной GitHub Pages менять не нужно. Адрес pages.dev до завершённого deployment не считается созданным или проверенным.

В этой среде доступ к панели/документации Cloudflare заблокирован сетевым прокси, поэтому текущие подписи интерфейса и сам deployment не проверены. Если пункты интерфейса отличаются, пришлите скриншот панели без секретов. После публикации пришлите фактическую ссылку для проверки.
